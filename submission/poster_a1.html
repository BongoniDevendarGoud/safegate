🛡️ 1. Problem Statement & Motivation

Generative AI and neural synthesis (GANs, Diffusion, face-swapping) allow adversaries to generate highly realistic manipulated videos. Modern Web Application Firewalls (WAFs) only examine network packets, headers, and SQL/XSS signatures, treating video uploads as uninspected binary payloads.

Existing commercial deepfake scanners perform superficial sampling (1–2 frames/second), allowing malicious actors to bypass security using single-frame temporal splice attacks. Once published to a public platform, the reputational and social harm is instantaneous.

Core Objective: Build an in-line, fail-closed video upload firewall that decodes 100% of video frames, classifies every frame with AI models, and blocks unauthorized media before publication.

⚙️ 2. 7-Layer OSI Video Protocol Stack

SafeGate 2.0 enforces defense-in-depth across 7 protocol layers:

  • L1 - Physical Bitstream: Magic byte validation & quarantine buffering.
  • L2 - Temporal Frame Link: Complete frame extraction via FFmpeg/OpenCV.
  • L3 - Transport & Hashes: Frame-level SHA-256 fingerprinting.
  • L4 - Perceptual Session: pHash visual blocklisting & caching.
  • L5 - Forensic Presentation: Compression MSE & Laplacian variance.
  • L6 - Cognitive AI: PyTorch convolutional frequency classification.
  • L7 - Firewall Policy Gate: Tri-state decisioning (ALLOW/QUARANTINE/BLOCK).

⚡ 3. In-Line Firewall Architecture

🎨 4. Frame Color Classification System

Every extracted frame is visually stamped according to the strict inverted forensic convention:

🔴
RED — LEGITIMATE / AUTHENTIC FRAME
Natural CMOS sensor noise profile, consistent optical focus.
🟢
GREEN — SUSPICIOUS / AI-MANIPULATED
Synthetic frequency artifacts, high compression residuals.
🟡
YELLOW — UNCERTAIN / AMBIGUOUS
Low contrast, underexposure, or model inference failure.
